# Reference Audit Plan

Use OpenAlex for DOI/title/journal/year validation and NCBI/PubMed where papers
are biomedical or nanopore-related and indexed.

Reference categories to verify:

1. PNP and nanofluidic transport foundations.
2. Solid-state nanopore biointerfaces.
3. Scharfetter-Gummel / finite-volume electrodiffusion discretization.
4. PINNs and physics-informed machine learning.
5. PINNs for stiff, multiscale, or coupled PDEs.
6. Data assimilation in PINNs.

Each formula in the manuscript must map to either:

- a derivation in the Methods section,
- a standard continuum transport reference,
- or a discretization reference for the numerical baseline.
