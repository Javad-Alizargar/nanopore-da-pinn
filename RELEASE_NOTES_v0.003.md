# Release Notes: v0.003

This release is prepared for the full-length Applied Surface Science manuscript
reproducibility archive.

## Added Since v0.002

- Coupled PNP charged-wall DA-PINN benchmark outputs for
  `surface_wall_0p036mC`.
- Three-grid SG/FV current-conservation and grid-refinement diagnostics.
- Exact-boundary PINN versus DA-PINN ablation outputs.
- Surface-response sweep showing current-voltage behavior and wall-charge ion
  redistribution.
- Figure-generation support scripts and numerical outputs needed to reproduce
  manuscript tables and supplementary results.

## Not Included

The journal manuscript source files, manuscript PDF, cover letter, graphical
abstract source, and submission package are deliberately not included in this
public reproducibility release.
